## What it does

Records/imports original narration and pictures; creates local 16:9 / 9:16 / 4:5 / square H.264/AAC MP4; preserves projects and SHA-verified full-media backups. The **major-only visual planner** keeps pictures stable through incidental rain/dialogue/characters and proposes changes for major setting or dramatic transitions. **Important-only artwork brief** lists genuinely needed pictures. Optional local Whisper.cpp speech transcription requires a separately installed multilingual model and always needs Burmese text/timing review; an offline manuscript agreement guard refuses wildly incorrect SRT before scene timing suggestions.

**Not yet proven:** reliable end-to-end automatic comprehension of a full Burmese novel recording, precise spoken-word timing, Burmese-specific model integration, user's personal Windows laptop, and unsigned-publisher warning removal. **No private novel or personal voice is in this release.** Installer requires no paid video service.
