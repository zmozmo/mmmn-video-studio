# Offline local picture choices for IMPORTANT existing scenes — v0.15.5 research

Only import/user-chosen image filenames and editable tags are used. No image
recognition, web downloads, AI generation, external stock images or claims
about unrestricted copyrights. The user remains responsible for the rights.

Reuses the existing major-only storyboard and NEVER inserts an additional
scene boundary for rain, minor dialogue or incidental character mentions.

One unique grounded location label on a local image can propose it. If two
pictures score similarly, the choice remains ambiguous and unresolved.
Changes require explicit confirmation; suggestions are never marked as
manually approved. Existing photos, manual/timing locks and voice unchanged.

A technical rendering split can reuse the last photo without changing
visible backgrounds. No automatic cloud activity or private photo upload.

This standalone module and Node tests are a first step; a real Windows
UI button and independent native user flow must pass before calling it
part of any published installer.
