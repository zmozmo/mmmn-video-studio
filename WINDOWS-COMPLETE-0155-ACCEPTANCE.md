## Supported creative workflow

1. Author privately imports Myanmar chapter text and recorded voice.
2. Import or choose local images, optionally suggest already-imported images for major dramatic/location/atmosphere scene boundaries. A rain word, dialogue or ordinary character arrival does not automatically demand a picture change.
3. Offline Burmese CPU Model generates an approximate, private, unapproved SRT. Manuscript match, SRT chronology and whole-audio coverage are checked before any automatic timing proposal.
4. Review any important-scene/SRT cue and approve the photo and timestamp; manual locks and backup data survive editing.
5. Preview, save, export offline H.264/AAC MP4 and make local full-media backup.

## Still NOT fully implemented, certified or proven

- Full automatic semantic comprehension of entire private Myanmar novels, and perfect discovery/timing of important scenes.
- Generating or web-scraping new illustrations automatically inside a **fully offline** Windows app. The current local artwork suggestion feature only selects already imported images by labels.
- Accurate word-level alignment of a real **90-minute** voice recording; six publicly licensed test clips and time-segmentation tests do not prove that.
- Author's personal Windows laptop installation and performance acceptance with real private manuscript/voice; never publish private files to GitHub for testing.
- Android offline app, direct Google Drive author syncing, and signed Windows publisher binary.

## Release gating principles

- Never replace original narrator audio, author manuscript, confirmed subtitles, manual scene/photo locks or backup files without explicit author action.
- Do not report ASR confidence as reliable unless independent source and author-accent tests support it.
- Keep one visible photo stable for long passages; internal renderer segments are not picture switches.
- Keep the one-file setup checksum pinned. Never publish an untested, rebuilt installer under the existing release tag.
- Treat a full 90-minute novel author-recording acceptance run as the only proof of that private production workload.
